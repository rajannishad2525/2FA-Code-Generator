# 🔐 2FA Code Generator

A lightweight client-side **TOTP (Time-Based One-Time Password) 2FA Code Generator** built using pure **HTML, CSS, and JavaScript**.

Enter a Base32 secret key and generate a **6-digit 2FA code** that automatically refreshes every 30 seconds.

## ✨ Features

* 🔐 Generate 6-digit TOTP codes
* ⏱️ Automatic 30-second code refresh
* 🌐 Runs completely in the browser
* 🚫 No Python or backend required
* 📦 No external libraries or dependencies
* 🎨 Simple and responsive interface
* 🔒 Secret key is processed locally in the browser

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* Web Crypto API
* HMAC-SHA1
* TOTP

## 🚀 How to Use

1. Clone the repository:

```bash
git clone https://github.com/rajannishad2525/2FA-Code-Generator.git
```

2. Open the project folder.

3. Open `index.html` in your browser.

4. Paste your Base32 secret key.

5. Click **Generate Code**.

6. Your 6-digit TOTP code will be displayed and refreshed automatically.


This project is designed to process the secret key **locally in the browser**. It will work for everything—Instagram, Google, and all the secret accounts.
